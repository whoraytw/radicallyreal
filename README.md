# Radically Real website

Static HTML/CSS site prepared for GitHub + Cloudflare Pages.

## Files
- `index.html` — link-in-bio style homepage
- `about.html` — About Radically Real
- `contact.html` — contact page
- `styles.css` — site styling
- `assets/radically-real-logo.png` — supplied logo asset

## Before launch
1. In `index.html`, replace the first `href="#"` with your Kit free-guide signup URL.
2. Replace the second `href="#"` with your Kit general signup URL.
3. Activate `hello@radicallyrealrae.com` in Google Workspace.
4. Upload this folder to a GitHub repository.
5. Connect that repository to Cloudflare Pages.
6. Point `radicallyrealrae.com` to the Cloudflare Pages project.
